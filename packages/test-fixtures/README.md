# Test fixtures

The `office/visual-*` files are deterministic, sanitized documents generated by
`services/document-engine/tools/MergeCom.FixtureGenerator`. They contain only
synthetic names and values. Regenerate them with:

```sh
dotnet run --project services/document-engine/tools/MergeCom.FixtureGenerator -- packages/test-fixtures/office
```

`macro-word.docm`, `external-link-excel.xlsx`, and `corrupt-office.docx` are
negative security fixtures. They must never be rendered into downloadable pilot
artifacts.

Only synthetic data belongs here. Do not commit customer documents, credentials, or
production-derived data.

`office/valid-word.docx` is built only from the adjacent synthetic XML source.
Adversarial macro, signature, external-link, traversal, DTD, compression-ratio,
oversized-part, and corrupt packages are generated in the document-engine test
suite so no active content is committed.
